# Cloud Computing & AWS Infrastructure — CMIT 326 | UMGC
Verified coursework from the University of Maryland Global Campus.  
Topics covered: Cloud migration strategy, AWS VPC architecture, EC2 deployment, security groups, cloud vendor analysis, and infrastructure cost reduction.




---

## 🗂️ Project Scenario

All projects in this course were completed in the role of an IT team member for **Don & Associates** — a fictional financial consulting firm looking to migrate from on-premises infrastructure to the cloud to reduce costs and enable expansion.

---

## 📄 Projects

| Assignment | Description |
|------------|-------------|
| [Assignment 1 — Executive Summary](Executive-Summary-Cloud-Migration.md) | High-level overview of cloud computing types, major vendors, and migration benefits/risks |
| [Assignment 2 — Cloud Vendor Presentation](CloudPresentation-Brandy-Haynes-7384.pptx) | Detailed comparative analysis of AWS, Azure, and Google Cloud presented to company leadership |
| [Assignment 3 — Proof of Concept Report](Proof-of-Concept-Report-AWS-VPC.md) | Hands-on AWS lab — built a VPC, configured public/private subnets, created security groups, and launched an EC2 web server instance |

---

## 🛠️ Skills Demonstrated

- **AWS VPC Architecture** — Designed and deployed a Virtual Private Cloud with public and private subnets
- **EC2 Deployment** — Configured and launched a web server instance into the VPC
- **Network Security** — Created and configured VPC security groups as virtual firewalls
- **NAT Gateway Configuration** — Enabled internet access for private subnet resources
- **Cloud Vendor Analysis** — Evaluated AWS, Microsoft Azure, and Google Cloud Platform
- **Infrastructure Cost Analysis** — Developed cost reduction strategy for on-premises to cloud migration
- **Technical Documentation** — Authored executive summaries, proof of concept reports, and comparative analyses
